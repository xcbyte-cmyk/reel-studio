# Reel Studio

주제 입력 → 대본 → 한국어 내레이션 → 세로 영상 편집·자막 → 파일 내보내기 / 승인 후 게시 / 자동 게시를 처리하는 로컬 앱입니다.

## 실행

**Windows에서 `Start.cmd`를 더블 클릭**합니다. 브라우저에서 <http://127.0.0.1:18765>가 열립니다. Python, Pillow, requests, FFmpeg와 ffprobe가 필요합니다. Windows 로컬 내레이션을 사용하려면 한국어 음성도 설치되어 있어야 합니다.

처음 설정할 때는 앱 왼쪽 메뉴의 **초기 설정 가이드** 또는 <http://127.0.0.1:18765/#setup>를 여세요. 제작 환경 확인, 선택적인 AI 연결, Instagram 연결 방식별 절차, 첫 영상 제작, 게시·매일 자동화 설정을 순서대로 안내합니다. 각 단계의 버튼으로 실제 설정 화면에 이동할 수 있습니다. 작업 기록이 없는 새 설치에서는 가이드가 먼저 열립니다.

명령줄에서 직접 실행할 수도 있습니다.

```powershell
python -m pip install -r requirements.txt
python server.py --open
```

FFmpeg와 ffprobe는 PATH에 있어야 합니다. Windows 설치 명령은 `winget install --id Gyan.FFmpeg -e`입니다. `Start.cmd`로 실행한 서버는 백그라운드에서 유지됩니다. 로그는 `data/server.log`, `data/server-error.log`에 저장됩니다. 직접 실행한 경우 Ctrl+C로 종료합니다.

## 콘텐츠 모드 3가지

| 모드 | 입력 | 제작 방식 |
|---|---|---|
| 정보·지식 | 주제, 시청자, 참고 자료 | 훅·핵심·CTA 대본, 장면 카드, 한국어 내레이션, 자막 |
| 상품·브랜드 | 제품 설명, 사진·영상, 브랜드, CTA | 업로드한 자료를 장면별로 배치하고 홍보 대본·내레이션·자막 합성 |
| 하이라이트 | 원본 영상, 선택적 시작·종료 초 | 원본 영상에서 한 구간 추출, 9:16 변환, 원본 음성 보존 |

AI 키가 없으면 정보·상품 모드는 **입력 자료를 배치하는 템플릿 초안**을 사용합니다. 제공한 자료 없이 제품 특징이나 구체적인 사실을 자동 조사하지 않습니다. 최신 정보를 다룰 때는 참고 자료에 실제 내용을 넣어 주세요. AI 키를 연결하면 주제·자료에 맞는 대본을 생성합니다.

하이라이트는 시작·종료 시각을 입력하면 해당 구간을 사용합니다. 시각을 비우고 AI 키를 연결하면 **전체 원본 음성 전사 → 후보 구간 비교 → 한 개 하이라이트 선정 → 실제 전사 자막 합성** 순서로 처리합니다. 전사는 10분 단위로 저장해 중단 후 재개할 수 있습니다. 키 없이 시각을 비우면 중앙 구간을 사용하며 의미 기반 선정은 하지 않습니다. 전사하지 않은 원본의 대사 자막은 생성하지 않습니다. 현재 자동 선정은 음성 내용 기준이며 장면의 시각적 중요도나 화자 얼굴을 추적하지 않습니다.

영상 배경의 별도 생성, 스톡 영상 검색, Instagram 음원 라이브러리 음악 선택은 포함되어 있지 않습니다. 상품·실사 화면은 직접 업로드한 파일을 사용합니다.

## 게시 방식 3가지

| 방식 | 동작 |
|---|---|
| 파일 생성 | 영상·커버·SRT·대본 JSON·게시 문구를 파일로 저장 |
| 승인 후 게시 | 제작 후 대기. 화면에서 승인하면 즉시 또는 지정 시각에 게시 |
| 자동 게시 | 전체 제작 실행 후 즉시 또는 지정 시각에 Instagram 게시 |

`대본 생성`은 대본까지만 처리합니다. `영상 제작`은 미리보기 영상까지만 처리합니다. `전체 제작`은 선택한 게시 방식까지 이어집니다. 게시된 콘텐츠나 이미 Instagram 업로드가 시작된 작업을 바꾸려면 새 작업을 만드세요. 파일 제작 후 대본·자료를 수정하면 재제작이 필요합니다.

**예약·매일 자동 제작은 이 앱과 PC가 켜져 있는 동안 동작합니다.** PC가 꺼져 있는 동안에는 제작·게시할 수 없습니다. 다시 켜면 지난 개별 예약을 처리하며, 매일 자동화는 당일 실행 시각이 지났고 당일 실행 기록이 없으면 당일 작업 한 건만 생성합니다. 과거 여러 날짜의 작업을 몰아서 만들지는 않습니다. 처음 규칙을 활성화할 때 시각이 이미 지났다면 다음 날부터 시작합니다.

자동화 메뉴에서 주제를 한 줄에 하나씩 입력하고, 매일 제작 시작 시각·콘텐츠 모드·게시 방식을 선택합니다. 주제는 순환합니다. 지정 시각은 제작 **시작** 시각이며, 완성 시점은 원본 길이·음성 생성·인코딩 시간에 따라 달라집니다. 규칙 생성 전 입력한 자료·브랜드 등 제작 설정을 템플릿으로 재사용합니다. 기본적으로 활성화된 반복 자동화는 없습니다.

## 계정 연결

설정 화면에 직접 입력합니다. 이 앱의 API 호출은 Codex 대화의 구독 사용량과 별개로 해당 API 계정에 청구됩니다.

- **OpenAI API 키:** 맞춤 대본 및 자동 하이라이트 전사·선정에 사용. 음성은 무료 로컬 Windows 음성, OpenAI 음성, 무음 중 선택합니다. 모델명은 화면에서 변경할 수 있습니다. 기본 대본 모델은 `gpt-4.1-mini`, 음성 모델은 `gpt-4o-mini-tts`, 전사는 `whisper-1`입니다.
- **Instagram 사용자 ID + 액세스 토큰:** 실제 게시에 필요합니다. Instagram 사용자명이나 계정 비밀번호를 넣는 칸이 아닙니다. 비즈니스 또는 크리에이터 계정과 게시 권한을 가진 Meta 앱 구성이 필요합니다.
- **Instagram Login:** 공개 미디어 서버가 필요합니다. 공개 기본 URL 아래 `/exports/작업ID/reel.mp4` 등 실제 출력 파일 경로를 Meta가 내려받을 수 있어야 합니다. URL을 입력한다고 자동 호스팅되지는 않습니다.
- **Facebook Login:** 연결된 Facebook Page와 게시 권한 설정이 필요하며 로컬 파일을 Meta로 직접 전송합니다.

자세한 계정·권한·토큰·호스팅 설정은 [INSTAGRAM.md](INSTAGRAM.md)를 참고하세요. API 키와 토큰은 이 컴퓨터의 `data/settings.json`에 저장됩니다. 설정 조회 응답에는 실제 키 값 대신 입력 여부만 포함됩니다. 환경 변수 `OPENAI_API_KEY`, `INSTAGRAM_ACCESS_TOKEN`, `INSTAGRAM_USER_ID`도 사용할 수 있습니다.

## 결과물과 동작

이 컴퓨터에서 실제로 생성한 샘플:

- [정보형 · 한국어 내레이션과 자막, 약 38초](exports/74f42cc4cd66/reel.mp4)
- [상품형 · 디지털 가이드 소개 데모, 약 16초](exports/2b3e5fbc7dfd/reel.mp4)
- [하이라이트형 · 원본 음성을 보존한 구간 추출, 약 9초](exports/898d4882b4f3/reel.mp4)

상품 샘플은 기능 시연용이며 실제 판매 상품이 아닙니다. 로컬 실행 중인 앱의 보관함에서도 샘플을 열 수 있습니다. 배포용 ZIP은 앱 소스와 샘플 결과물을 포함하며 개인 설정·로컬 작업 데이터베이스는 포함하지 않습니다.

결과는 `exports/<작업ID>/`에 저장됩니다. 대표 결과물은 MP4 영상, PNG 커버, SRT 자막, `script.json`, `caption.txt`입니다. 영상은 세로 1080×1920, 30fps, H.264/AAC를 사용합니다. TTS 실제 길이에 맞춰 장면 시간이 조정되므로 목표 영상 길이와 완성 길이는 다를 수 있습니다.

제작 기록과 예약 상태는 SQLite `data/studio.sqlite`에 저장됩니다. 원본 파일은 `data/assets/`에 보관됩니다. 중단된 제작은 실패 상태로 표시하고 재시도할 수 있습니다. Instagram 게시 요청의 응답이 유실되면 저장된 컨테이너 상태를 조회하며, 중복 게시가 발생할 수 있는 무조건 재전송은 하지 않습니다. 게시 여부가 확인되지 않으면 화면의 오류 안내에 따라 계정에서 확인합니다.

최초 제공 시점에는 실제 Instagram 계정과 OpenAI API 키가 연결되어 있지 않습니다. 로컬 제작 결과와 외부 API 연동 코드를 제공하며, 계정별 권한·토큰·외부 API 호출 및 실제 게시 성공 여부는 연결 후 확인해야 합니다.

## 구성

- `server.py`: 로컬 HTTP API 라우팅과 서버 시작·종료
- `studio/http.py`: JSON 응답, HEAD 요청, 파일·영상 구간 스트리밍
- `studio/assets.py`: 원본 파일 업로드와 첨부파일 조회
- `studio/content.py`: 템플릿 / AI 대본
- `studio/media.py`: 영상, 내레이션, 자막, 커버 합성
- `studio/highlights.py`: 전체 원본 전사, 후보 비교, 하이라이트 선정
- `studio/instagram.py`: Meta 업로드·게시·처리 상태 조회
- `studio/production.py`: 대본·하이라이트 준비와 결과물 생성 순서
- `studio/workflow.py`: 작업 실행 제어, 승인, 게시, 재시도
- `studio/scheduling.py`: 예약 시각 처리와 매일 자동 제작. 작업 제출 함수를 전달받아 실행
- `studio/store.py`: 제작 기록 및 설정 저장, SQLite 연결 수명 관리
- `static/`: 한국어 제작 화면

Python 3.11 이상과 FFmpeg가 필요합니다. Windows 이외에서는 OpenAI TTS 또는 무음을 선택하고 한국어 글꼴을 설치해야 합니다. 외부에서 접속하는 다중 사용자 웹 서비스 배포용으로 구성한 앱은 아닙니다.
