# Implementation contract

Python 3.11+, stdlib HTTP server, Pillow and requests. Root owns server.py, studio/store.py, studio/content.py, studio/workflow.py, README and launcher. No test/security/safety/hash code or multi-agent review.

Job shape: id, title, topic, mode (knowledge/product/highlights), delivery (export/approval/auto), status (draft/generating/rendering/ready/approved/scheduled/publishing/published/failed), progress, message, created_at, updated_at, scheduled_at (ISO UTC or null), auto_publish (bool), tone, audience, brand, cta, duration (seconds), assets (list of {id,name,path,url,kind}), source_notes, clip_start (seconds), clip_end (seconds), script ({title,hook,scenes:[{text,narration,duration}],caption,hashtags:[]}), artifacts ({video,cover,subtitles,script,caption,duration,...}), events:[], error, publish_state:{}.

Settings: openai_api_key, openai_model (gpt-4.1-mini), tts_provider (windows/openai/none), openai_tts_model (gpt-4o-mini-tts), openai_voice (coral), instagram_token, instagram_user_id, instagram_login (instagram/facebook), instagram_api_version (v23.0), public_base_url, share_to_feed (true). GET never returns secret values, only configured booleans openai_configured/instagram_configured. All paths exported as /exports/{jobid}/{filename}, raw paths kept internally. Asset path is absolute local file. Data in data/ and exports/ relative to app root.

HTTP JSON response envelopes are NOT used unless specified. GET /api/state -> {jobs:[],settings:{...},capabilities:{ffmpeg,pillow,windows_tts},automations:[]}. GET /api/jobs/{id} -> job. POST /api/jobs -> job (creates draft with input fields). PATCH /api/jobs/{id} -> job (edit draft/ready/failed). POST /api/jobs/{id}/generate -> job (background script generation only). POST /api/jobs/{id}/render -> job (background video render; creates script if absent). POST /api/jobs/{id}/run -> job (background script plus render plus selected delivery). POST /api/jobs/{id}/approve -> job (approve and post now or at scheduled_at). POST /api/jobs/{id}/publish -> job (explicit immediate publication). POST /api/jobs/{id}/retry -> job. POST /api/assets?name=filename uses raw file body -> asset {id,name,path,url,kind}; no multipart. GET asset.url streams file. POST /api/settings -> public settings, blank secrets preserve existing unless clear_openai/clear_instagram true. Errors HTTP non-2xx {error:message}. Jobs polled ~2s during active work.

Automations: POST /api/automations with {name,enabled,mode,delivery,topics:[strings],time:"09:00",timezone:"Asia/Seoul",template:{job fields}} -> automation. GET /api/automations -> list. PATCH /api/automations/{id} allows enabled/settings. Daily rotation of topics using local app scheduler while running. GET /api/health -> basic status. Scheduler lives root workflow. No actual schedule enabled without user setting one.

Media module contract: studio/media.py exports render_job(job:dict, settings:dict, output_dir:Path, progress:callable=None)->dict of artifact file paths (absolute strings for video,cover,subtitles,script,caption), duration, and optional warnings. progress(percent:int,message:str). Also capabilities()->dict. Handles three modes. Windows TTS installed Microsoft Heami Desktop ko-KR; requests/Pillow/ffmpeg/ffprobe already installed. All media functionality owned by media agent.

Publisher module contract: studio/instagram.py exports publish_reel(job:dict,settings:dict,video_path:Path,progress:callable=None,save_state:callable=None)->dict {media_id,permalink,container_id,...}; progress(percent,message); save_state(dict) persists publish_state eagerly for retry. job['publish_state'] persisted between attempts. Also connection_status(settings)->dict if useful. Implement direct local binary upload where officially supported (Facebook Login) and public video_url for Instagram Login. No live publishing or secret discovery. Publisher docs in INSTAGRAM.md. Root invokes only user-selected flows when configured.

Frontend owned entirely by frontend agent in static/index.html, app.js, styles.css. Korean interface, attractive production studio (ink + warm offwhite, orange accent), mode and delivery choices, source file upload, optional highlights timestamps, editable script scenes/caption, video preview, jobs/status, settings drawer, daily automation configuration. No fake metrics or fake connected state. Public account/API settings entry, secret values blank, configured status only. UI should make no remote asset dependency. If no API key template script mode is explicit. Local app top-level title Reel Studio.
